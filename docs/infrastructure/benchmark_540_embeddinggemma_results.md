> **💡 実測データに基づく重要インサイト**:
> 1. **MRL 次元削減耐性**: EmbeddingGemma 2 は 768d (F1=0.6069) から 256d (F1=0.6137) や 128d (F1=0.6140) へ次元を落としても、F1 スコアや分離性能の低下が見られませんでした。ストレージ容量を 67%〜83% 削減しながら同等の性能を維持できます。
> 2. **CPU 推論速度の優位性**: 1テキストあたり **29.6 ms** で動作し、同等パラメータの ruri-310m (58.6 ms) や bge-m3 (75.9 ms) と比較して **2〜2.5倍高速** に完了しました。
> 3. **ニアミス識別と Logit Gate 二段カスケードの有効性**: バイエンコーダー（埋め込み単独）では、同一トピックで回答事実だけが抜けた「ニアミス」との分離ギャップが各モデルとも僅差（Gap = -0.003 〜 +0.024）に留まります。無関係文書の除外（Gap = +0.17）にはバイエンコーダーで十分ですが、回答事実の厳密な足切りには Stage 2 として Logit Gate (Qwen3.5-0.8B) を組み合わせる二段カスケード構成が有効であることが 540件の実測から確認されました。
